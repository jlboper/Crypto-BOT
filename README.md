# Crypto AI Trader — canal estable de actualizaciones

Este repositorio público distribuye las actualizaciones verificadas de Crypto AI Trader.

- `latest.json` anuncia la versión estable vigente.
- `packages/` contiene los paquetes versionados.
- La aplicación descarga únicamente por HTTPS y valida tanto el tamaño como la huella SHA-256 antes de instalar.
- Cada instalación requiere confirmación del usuario, crea un respaldo, ejecuta las pruebas y reinicia el motor.

Este repositorio no contiene claves, credenciales, posiciones, bases de datos, registros ni respaldos del usuario.
